4. TXT FILE CHECKER
==================================================

When the user presses:

📄 CHECK TXT

tell them:

📄 ZYPHRA TXT ANALYZER

Send your .txt file as a Telegram document.

The bot should accept only TXT files.

After receiving a TXT document:

1. Check extension.
2. Check file size.
3. Download the document temporarily.
4. Read it as UTF-8 text.
5. Process it.
6. Delete the temporary uploaded file afterward.
7. Never permanently store sensitive record contents.

Show a progress/loading sequence such as:

⏳ Preparing analyzer...
🔎 Reading file...
🎮 Detecting game...
🧹 Removing duplicates...
📊 Generating results...
✅ Complete!

Do not fake progress for an excessive amount of time.

7. STATUS DETECTION
==================================================

The analyzer should classify records based ONLY on status information already contained in the TXT.

VALID indicators:

VALID
CLEAN
SUCCESS

INVALID indicators:

INVALID
FAILED
FAIL

If both VALID and INVALID appear in the same record:

INVALID takes priority.

Anything without a recognized status:

UNKNOWN

Do NOT infer that an account works merely because an email, username, UID, or password exists.
